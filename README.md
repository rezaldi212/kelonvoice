# kelonvoice — Voice Word Bank

Aplikasi desktop untuk membangun bank kata audio dari sumber suara seseorang, lalu menyusun kalimat baru dengan menyambung potongan-potongan audio kata tersebut.

## Menjalankan

```bash
python main.py
```

## Dependensi

- `customtkinter`
- `pydub`
- `yt-dlp`
- `faster-whisper`
- `pygame-ce`
